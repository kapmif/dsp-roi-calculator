# Contributing to dsp-roi-calculator

Thanks for your interest. This is a real operational problem — contributions that improve accuracy are genuinely useful.

## What we're looking for

- **Better data**: If you work in logistics and have actual mis-sort rate data, open an issue
- **Improved formulas**: Sensitivity analysis, wage growth projections, shift-pattern modeling
- **International data**: EU, UK, APAC DSP market numbers in `data/`
- **Better browser UI**: The `calculator.html` chart could be improved
- **Bug fixes**: If a number looks wrong, open an issue first to discuss

## How to contribute

1. Fork the repository
2. Create a branch: `git checkout -b fix/description`
3. Make your change
4. Run the tests: `python -m pytest tests/`
5. Open a pull request with a clear description of what you changed and why

## Opening issues

If you think a formula assumption is wrong or the numbers don't match your real-world experience, open an issue and describe what you'd expect. We want this calculator to reflect reality, not theory.
